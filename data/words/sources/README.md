# Beginner vocabulary list (JLPT N5 and N4)

`jlpt_n5.csv` and `jlpt_n4.csv` are unchanged copies of
`original_data/n5.csv` and `original_data/n4.csv` from

  https://github.com/stephenmk/yomitan-jlpt-vocab
  commit b062d4e38c4bdd0950ae1d4ec55f04b176182e03

Only the file names were changed.

## Authors and licence

- The word lists were compiled by Jonathan Waller and published on his
  JLPT Resources page (http://www.tanos.co.uk/jlpt/) under the Creative
  Commons Attribution (CC BY) licence.
- Stephen Kraus matched each word to its entry in JMdict (the
  `jmdict_seq` column) and replaced some rare spellings with common ones.
  His repository is licensed CC BY-SA 4.0
  (https://creativecommons.org/licenses/by-sa/4.0/).

These copies are distributed here under CC BY-SA 4.0.

## How the licence was established

The CC BY statement for the original lists is taken from the README of the
repository above, and agrees with how other projects that use the same
lists (for example jisho.org) describe them. It was not read from a
licence file published by Jonathan Waller himself. If you know it to be
wrong, please open an issue.

## Note

There are no official vocabulary lists for the JLPT. These lists are an
informed estimate of what each level covers, and are used here only to
choose which words a beginner meets first.
